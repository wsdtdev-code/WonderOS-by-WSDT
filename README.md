Hi! this is my creative OS project, WonderOS.
its secure, creative, and 100% safe to use!
versions older than 4.4 are done with plain C++
while 4.4 and above uses VB.NET
WonderOS can work on windows as a simulator and can work on a computer due to the bootloader!
all OSes depend on thingsto work, like Windows MacOS, Linux, and more!
How to run:
Extract the ZIP file then:
if the version is below 4.4:
Run the file directly
If its 4.4 or above:
1. copy the WonderOS folder ('WonderOS_X', 'WonderOS_26', 'WondeerOS_10' etc...) directly to C:\ to work properly
2. go to: "C:\WonderOS[version name]\System\bootloader\"
3. run the bootloader file
4. let it boot automatically
please enjoy!
